# LEIA-ME

O título grande "LEIA-ME" não foi colocado ao acaso. Quero que você saiba algo sobre este material desde o início:

{% hint style="info" %}
Todo ele foi escrito primeiro por uma ferramenta de IA e, depois, revisado por mim (Prof. Natan). As primeiras aulas tiveram como primeiro rascunho o Gemini Notebook; as seguintes, o Claude. Meu papel na elaboração deste material está mais para um _orquestrador_ que um _autor_. Minha orquestração consistiu em:

* Realizar uma curadoria dos melhores materiais sobre determinado tópico para que servissem de fonte à ferramenta;
* Fabricar o _prompt_ mais adequado para obter o melhor primeiro esboço do conteúdo;
* Revisar o material gerado pela ferramenta;
* Incluir conteúdo, exemplos e atividades não gerados inicialmente pela ferramenta.
{% endhint %}

> Eu farei uso intensivo de IA enquanto Professor neste semestre. Sei que vocês farão o mesmo como alunos. Acho que é o certo a fazermos: usar a IA como ferramenta de automação para nos tornar mais eficientes. O importante é aprendermos a fazer isso bem feito!

## Sobre o material

As aulas partem de um conjunto de dados real e chegam às contas por ele — nada de fórmula sem exemplo numérico. Os dados usados aqui vêm da planilha de vendas de uma pizzaria: 48.620 itens vendidos, distribuídos em 21.350 pedidos, entre janeiro de 2025 e agosto de 2026.

O caminho da disciplina está no [Roadmap](roadmap.md). As aulas publicadas estão no sumário à esquerda.
