# Antes da Aula 6 · Prepare o Seu Computador

Nas próximas cinco aulas, você vai construir e publicar cinco projetos com ajuda de IA. Cada aula tem 2h30. Se a instalação acontecer em casa, sobra tempo de aula para o que importa: entender a IA e usá-la bem.

Faça tudo abaixo antes da Aula 6. Leva uns 40 minutos. O computador do laboratório também serve: lá você pode instalar o que precisar.

## As quatro contas

| Conta | Para quê | Onde |
| --- | --- | --- |
| **Google pessoal** (gmail.com) | entrar no Antigravity | accounts.google.com |
| **GitHub** | guardar o código e publicar os sites | github.com |
| **OpenRouter** | usar modelos de IA por API na Aula 10 | openrouter.ai |
| Chat de IA de sua preferência | conversas rápidas e comparação de respostas | ChatGPT, Claude ou Gemini |

{% hint style="warning" %}
Use uma conta Google **pessoal**. Contas institucionais (do Google Workspace da faculdade ou da empresa) podem não funcionar no Antigravity.
{% endhint %}

No GitHub, escolha o nome de usuário com cuidado. Ele vira o endereço do seu site: o usuário `anasilva` publica em `anasilva.github.io`. Prefira algo profissional e curto.

{% hint style="info" %}
Estudantes podem pedir benefícios gratuitos. O **GitHub Education** (education.github.com) dá acesso a ferramentas pagas. O Google também oferece planos de IA para universitários (one.google.com/ai-student). As condições mudam com frequência: confira no site antes de assinar qualquer coisa.
{% endhint %}

## Os três programas

**1. Git.** É o programa que tira "fotos" da sua pasta de projeto e as envia ao GitHub.

* Windows: baixe em git-scm.com e aceite as opções padrão do instalador.
* macOS: abra o Terminal e digite `git --version`. Se não estiver instalado, o próprio sistema oferece a instalação.

**2. Google Antigravity.** É o ambiente onde o agente de IA trabalha com você. Baixe em antigravity.google, instale e entre com a sua conta Google pessoal.

**3. Python.** Só é usado na Aula 10, mas instale agora. Baixe a versão mais recente em python.org.

{% hint style="warning" %}
No instalador do Python para Windows, marque a caixa **"Add python.exe to PATH"** na primeira tela. Sem ela, o computador não encontra o Python depois.
{% endhint %}

## Teste de cinco minutos

Abra o Antigravity, crie uma pasta vazia chamada `teste-ia` e peça ao agente:

```text
Verifique se o git e o python estão instalados neste computador e me diga as versões.
Depois crie um arquivo ola.html com a frase "Funcionou!" e abra no navegador.
```

O agente vai pedir permissão para rodar comandos no terminal. Leia o comando e aprove. Se aparecer "Funcionou!" no navegador, está tudo pronto.

## Se algo der errado

| Sintoma | O que fazer |
| --- | --- |
| "git não é reconhecido como comando" | reinstale o Git e reinicie o computador |
| "python não é reconhecido" | reinstale o Python marcando "Add python.exe to PATH" |
| o Antigravity não aceita a conta | use uma conta gmail.com pessoal |
| o agente parou com aviso de limite | o plano gratuito tem cota semanal; em aula, trabalhe em dupla e alterne quem usa a cota |
